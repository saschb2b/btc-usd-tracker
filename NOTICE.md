# Third-party artwork

`bitcoin-symbolic.svg` is the **filled Bitcoin icon** from the
[Bitcoin Design Community's Bitcoin Icons](https://github.com/BitcoinDesign/Bitcoin-Icons).
It is copied byte-for-byte from the upstream SVG, with only the filename changed
to let GTK recognize it as a symbolic icon. The README preview reuses the same
artwork.
